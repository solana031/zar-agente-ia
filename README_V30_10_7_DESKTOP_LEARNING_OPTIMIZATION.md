# ZAR v30.10.7 — aprendizaje eficiente y escritorio

- Presupuesto máximo de 60 minutos por sesión inicial de aprendizaje.
- Reanudación inicia un nuevo presupuesto de hasta 60 minutos y continúa desde el último checkpoint.
- Búsquedas acotadas por tiempo para evitar sesiones bloqueadas.
- Estimaciones siempre limitadas a 60 minutos.
- Formato de duración: días, horas, minutos y segundos.
- Escritorio: el área de chat ocupa todo el espacio entre la navegación izquierda y el panel contextual derecho.
- El panel contextual evita accesos duplicados y prioriza secciones desplegables.
- Móvil mantiene sus accesos en el menú para conservar espacio.
