# ZAR v30.7.0 — Habilidades y aprendizaje observable

Cambios:
- El panel Habilidades muestra aprendizajes activos y completados aunque el formulario Enseñar a ZAR esté cerrado.
- Cada aprendizaje muestra fase, progreso, tiempo transcurrido, estimación, fuentes y consultas.
- El indicador del chat muestra cuando existe un aprendizaje en curso.
- Se amplió el reconocimiento de órdenes de aprendizaje desde el chat.
- El panel de habilidades refresca el estado de habilidades activas.
- Se corrigió el solapamiento visual inferior del compositor/sidebar con la barra de tareas de Windows mediante detección de espacio disponible.
- Se mantiene el almacenamiento de aprendizaje y habilidades fuera del release ZIP, en el volumen persistente.
