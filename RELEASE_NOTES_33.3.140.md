# ZAR 33.3.140

- ReposNews · ampliación de guías cortas (AdSense): en lugar de reescribir cada guía desde cero (lo que fallaba a menudo por comandos no verificables o por la revisión), ZAR amplía la guía ya publicada con secciones útiles (cómo funciona, casos de uso, errores comunes, alternativas, FAQ y valoración), usando la guía y la evidencia oficial del repositorio cuando existe.
- Las guías sin repositorio de GitHub (p. ej. jev, dramaclaw) también se amplían.
- Se mantienen las salvaguardas: ningún comando que no esté en la guía o en el README oficial, revisión independiente y publicación solo por el piloto automático del titular o su aprobación.
- Reintento a las 6 h (antes 24 h) y hasta 4 intentos; los intentos del sistema anterior no cuentan.
- Las propuestas del piloto automático que no llegaron a publicarse se reaplican sin gastar tokens; las obsoletas se descartan para poder reintentar la guía.
