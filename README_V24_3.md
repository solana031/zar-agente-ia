# ZAR V24.3

Cambios principales:
- En móvil se ocultan la barra lateral, panel derecho y botones rápidos.
- El compositor de mensaje queda fijo en la parte inferior con Adjuntar, Micrófono, Lectura y Enviar.
- El historial tiene scroll táctil independiente y controles de navegación.
- Nuevo menú desplegable desde la esquina superior izquierda.
- La acción principal del menú móvil es Reautorizar Google, destacada visualmente.
- El resto de funciones quedan accesibles dentro del menú.
- Escritorio mantiene la interfaz V24.2.
