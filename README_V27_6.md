# Zar V27.6 — Studio: editores funcionales de vídeo e imagen

## Correcciones
- "Nuevo vídeo" fuerza la creación de un proyecto nuevo y abre inmediatamente el editor con timeline.
- Si el backend de vídeo falla, el Studio muestra el error y ofrece reintentar en lugar de quedarse sin respuesta.
- "Cargar imagen" ya no usa el adjuntador general del chat: abre un editor fotográfico dedicado dentro de Zar Studio.
- Se añadió carga de imagen con guardado opcional en la biblioteca de Zar.
- Se puede elegir una imagen guardada y editarla sin descargarla.
- Editor de imagen funcional en navegador: brillo, contraste, saturación, desenfoque, giro, volteo, zoom, texto, restablecer, descargar copia y guardar copia en Zar.
- Diseño responsive para escritorio y móvil.

## Instalación
Sube el contenido del ZIP al repositorio, haz commit y deja que Railway despliegue. No requiere variables nuevas.
