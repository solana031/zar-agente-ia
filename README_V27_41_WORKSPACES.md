# ZAR V27.41 — Workspaces + adjuntos

- Calendario visual mensual de Zar conectado al Google Calendar principal.
- Reloj analógico + digital con hora local del dispositivo.
- Explorador de archivos persistentes con categorías, búsqueda, vista previa, apertura, descarga y eliminación.
- Los adjuntos del chat quedan pendientes hasta pulsar Enviar. Se pueden quitar con X antes de enviar.
- Al enviar se muestra el estado de subida y, al finalizar, nombre, tamaño, formato y ubicación lógica dentro de Archivos de Zar.

No requiere nuevas variables de Railway ni nuevas API keys.
