# ZAR v30.10.14 — Gmail rápido + Configuración + navegación

Cambios principales:
- El acceso rápido de Correo abre una tarjeta ZAR con los últimos correos recibidos de Gmail, mostrando remitente, asunto, fecha y fragmento; cada correo se puede abrir en una vista completa.
- Se eliminan los accesos rápidos Buscar en Internet y Calendario del compositor: ZAR ya puede buscar Internet desde lenguaje natural y Calendar sigue disponible en la pantalla principal/menús.
- El botón de menú superior izquierdo funciona en escritorio: permite ocultar/mostrar la navegación lateral.
- Nuevo botón ⚙️ Configuración en la esquina superior derecha.
- Configuración por usuario persistente: tema oscuro/claro, idioma preferido de respuesta y proveedor/modelo de IA.
- El idioma configurado se incorpora al prompt del agente como preferencia, sin impedir que el usuario pida otro idioma explícitamente.
- Herramientas y Cómo funciona salen del panel lateral y pasan a Configuración, con una sección ampliada de explicación.
- Los accesos centrales se mantienen adaptativos cuando está abierto el rail derecho.
- No se incluyen datos persistentes de usuarios, backups, jobs, bases SQLite/DB ni archivos de almacenamiento.
