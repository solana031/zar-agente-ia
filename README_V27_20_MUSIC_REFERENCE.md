# ZAR v27.20 — Music Reference Studio

- Analiza referencias musicales mediante búsqueda web pública.
- Extrae BPM/tempo, género, groove, instrumentación, energía y estructura de alto nivel.
- Aplica el perfil al proyecto de Audio Studio y genera una base procedural nueva.
- La referencia se conserva en el proyecto y se muestra en la interfaz.
- No descarga ni reproduce canciones de terceros ni copia melodías, letras, samples o grabaciones.
