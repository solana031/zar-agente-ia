# ZAR v30.4.1 — Mejora de Habilidades

Corrección visual y de interacción del panel de Habilidades.

- El panel de ejecución ocupa ahora todo el ancho de la tarjeta, en lugar de quedar comprimido en una sola columna.
- Se añadió una etiqueta clara para el trabajo concreto que se quiere ejecutar.
- La ejecución muestra estado de espera, éxito o error sin depender de ventanas `alert()` del navegador.
- Se deshabilita temporalmente la interacción del panel durante la ejecución para evitar dobles envíos.
- Se mantiene la ejecución desde el chat y el almacenamiento persistente por usuario de v30.4.0.
- No se incluyen datos runtime en el ZIP de release.
