# ZAR v30.8.0 — Aprendizaje visible y compositor profesional

## Cambios
- Al abrir 🧩 Habilidades se recuperan también los aprendizajes iniciados desde el chat.
- Los trabajos de aprendizaje se muestran con estado persistente: En curso, Pausado, Completado o Error, progreso, fase, fuentes, consultas y tiempo.
- Se mantiene la ejecución en segundo plano y la reanudación tras reinicio.
- El indicador del compositor sigue mostrando el aprendizaje activo y su porcentaje.
- El compositor de escritorio reserva espacio para evitar que la barra de tareas de Windows tape `Zar activo` o el cuadro de entrada.
- Los botones de adjuntar, voz, lectura y enviar ocupan toda la altura del recuadro, con un estilo uniforme y profesional, manteniendo sus handlers actuales.
- No se modifica el almacenamiento persistente ni las rutas de API existentes.
