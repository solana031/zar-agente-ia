# ZAR V24.3.2

Corrección centrada en el historial del chat móvil.

- El área del chat es ahora un contenedor de desplazamiento nativo y acotado.
- Deslizamiento táctil vertical activo en todo el historial.
- Dos controles visibles: ↑ para subir y ↓ para bajar.
- El botón ↓ lleva al final de la conversación.
- El botón ↑ lleva paso a paso hacia mensajes anteriores.
- Se mantiene el compositor fijo inferior y se conserva el espacio para que no tape el último mensaje.
- No se modifica la interfaz de escritorio.
