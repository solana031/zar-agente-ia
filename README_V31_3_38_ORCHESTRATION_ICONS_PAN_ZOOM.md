# ZAR v31.3.38 — Orchestration Icons + Pan & Slider Zoom

## Mejoras
- Iconografía de subagentes rediseñada con SVGs más limpios, modernos y profesionales.
- El zoom de la orquestación ahora usa una barra deslizante con thumb arrastrable.
- El porcentaje de zoom queda fijado al soltar el control.
- Se mantiene compatibilidad con botones `+`, `-` y `Reset`.
- El mapa de orquestación ahora se puede mover haciendo clic y arrastrando dentro del viewport.
- Se conserva la separación visual entre ZAR general y ZAR Stonks.

## Objetivo
Mejorar la legibilidad visual y la sensación tipo HUD/Jarvis, haciendo la exploración del mapa más cómoda y profesional.
