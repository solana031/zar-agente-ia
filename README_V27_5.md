# Zar V27.5 — Studio visual + experiencia móvil

Cambios principales:
- Botones destacados de Zar Studio y Editor de imágenes en el menú móvil, con tratamiento visual equivalente al botón de Google.
- Studio separado del chat y del centro de control.
- Al abrir Nuevo proyecto se muestra un lanzador de proyectos en vez de crear uno automáticamente.
- Superficie de trabajo negra, independiente y con estética de editor profesional.
- Modos Vídeo / Imagen / Audio visibles desde el Studio.
- En proyectos de vídeo se añade lienzo negro de previsualización, timeline visual y barra de herramientas del Studio sin eliminar los controles existentes.
- Se mantiene la edición por texto/voz y el backend de proyectos de V27.4.
- No se cambian las variables de Railway.
