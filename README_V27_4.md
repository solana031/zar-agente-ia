# Zar V27.4 — Centro de control + Studio separados

Cambios principales:
- Centro de control convertido en una pantalla independiente desde el menú izquierdo.
- Studio / Editor multimedia permanece como espacio de trabajo independiente.
- El chat principal queda como la pantalla principal de Zar.
- Nuevo diseño visual para las tarjetas y botones del Centro de control de escritorio.
- Tooltips de los iconos `i` del menú izquierdo ahora aparecen por encima de todo el contenido y no quedan recortados detrás del chat.
- Se mantienen las funciones e integraciones de V27.3.

Instalación cloud: sustituir el contenido del repositorio GitHub y hacer Commit changes. Railway hará el despliegue automáticamente si el servicio está conectado al repositorio.
