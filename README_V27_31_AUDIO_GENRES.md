# ZAR v27.31 — Audio Studio: biblioteca amplia de géneros y referencias

- Amplía el motor de Audio Studio a decenas de estilos: pop, rock, indie, punk, metal, trap, drill, hip-hop, R&B, soul, funk, reggaetón, dembow, dancehall, reggae, bachata, salsa, cumbia, merengue, samba, bossa, flamenco, afrobeat, house, deep house, techno, trance, psytrance, EDM, electro, dubstep, drum & bass, breakbeat, UK garage, grime, hardcore, hardstyle, gabber, frenchcore, speedcore, breakcore, jungle, synthwave, jazz, blues, fusión, clásica, neoclásica, barroco, cinematográfica, ambient, lo-fi y más.
- Añade alias naturales en español e inglés para órdenes por texto/voz.
- Cada estilo tiene BPM/escala/familia de síntesis y variaciones de groove/timbre; cada render conserva una semilla nueva.
- Las referencias de artistas/canciones se analizan desde información pública y se convierten en rasgos de alto nivel para crear una composición nueva.
- Se aceptan referencias de canción sin artista y URLs para intentar resolverlas mediante búsqueda web.
- No se descargan ni copian grabaciones, stems, samples, letras ni melodías de terceros.
