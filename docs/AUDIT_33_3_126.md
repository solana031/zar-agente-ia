## Límites y comprobación humana

- El repositorio no contiene MainActivity, AndroidManifest, Gradle ni fuentes de
  una APK. No es posible certificar/modificar su manejador nativo. No se intenta
  evadir las restricciones de Google WebView.
- La automatización del navegador del usuario está deshabilitada en Work. No se
  certificó una nueva autorización Google real ni las cuentas privadas actuales.
- La separación de scopes no demuestra borrado/revocación de tokens. No se
  enumeran ni reasignan automáticamente conexiones entre usuarios. Si el token
  real ha sido revocado, la vinculación rechaza el origen y se requiere OAuth.
- No se ejecutaron pagos, órdenes Paper/Live, generación pagada, publicación ni
  configuración de nuevas cuentas. No se tocaron secrets ni el backup Railway.

En móvil: recargar CUENTAS. Para OAuth, copiar el enlace HTTPS y abrirlo en
Chrome, completar allí la autorización y volver a ZAR. Para recuperar el espacio
del ordenador, generar el código en ese dispositivo conectado y pegarlo en
"VINCULAR ESTE DISPOSITIVO" del móvil; ZAR se recarga, sin copiar tokens.
Si la APK elimina sus cookies, se necesita volver a vincular; su código nativo
es necesario para investigar esa política de almacenamiento.
