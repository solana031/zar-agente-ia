# ZAR v31.3.41 — Orchestration Resizable Map Window

- El visor de Orquestación deja de estar limitado por la antigua regla de 430px.
- Altura inicial amplia (adaptativa al viewport).
- Ventana del mapa redimensionable desde la esquina inferior derecha.
- La barra superior izquierda permite mover la ventana completa.
- El mapa interior mantiene su propio pan por arrastre y zoom con rueda/slider.
- Tamaño y posición se guardan en localStorage para conservar la preferencia del usuario.
- En móvil se prioriza resize vertical y posición fija para evitar problemas de navegación.
