# ZAR V26 — Multimedia Cloud

## Novedades
- YouTube y Spotify funcionan correctamente cuando Zar está alojado en Railway: ya no dependen de `webbrowser` en el servidor.
- Nuevos comandos naturales: `busca ... en YouTube`, `abre ... en Spotify`, `pon ... en YouTube`, etc.
- El resultado devuelve un botón para abrir la búsqueda en el navegador del dispositivo.
- Panel visual `🎵 Multimedia` en escritorio y móvil.
- Se conserva el diseño y el chat inferior de V25.
- Se guarda en el contexto la última búsqueda multimedia.

## No requiere nuevas API keys
Esta versión usa URLs públicas de búsqueda de YouTube y Spotify. No necesitas configurar nuevas credenciales para probarla.
