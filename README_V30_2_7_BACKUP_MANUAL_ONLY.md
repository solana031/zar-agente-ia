# ZAR v30.2.7 — Backup manual y selección previa

- Abrir ZAR no inicia automáticamente una copia de Google.
- Conectar o reautorizar Google tampoco inicia automáticamente una copia.
- El usuario debe pulsar «Configurar y crear copia».
- El selector permite elegir todo o bloques/subbloques concretos.
- Se conserva la barra de progreso y el estado de la copia seleccionada.
- El texto del Centro de control deja claro que la copia es manual.

La copia sigue siendo exclusivamente de los datos Google autorizados; no copia el disco completo del ordenador.
